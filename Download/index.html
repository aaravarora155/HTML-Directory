Installation & Setup Guide

Windows Installation

WSL Environment Setup


  1. 1. WSL Installation

    Find Windows PowerShell in your Start menu, right-click, and run it as Administrator. Paste this command and hit Enter:

    wsl --install

    Once that's done, restart your computer. Upon restart, you will be prompted to setup an Ubuntu username and password to successfully install WSL.

    Note: when you type your password, it will not show up, just make sure you know what you are typing!

    To confirm it worked, run this command in PowerShell:

    wsl --list --verbose
  2. 2. Install VSCode & Extensions

    Download and install VSCode on Windows:

    Download VSCode

    Install the following extensions inside VSCode:

    • Motoko language extension (by Dfinity team)
    • Remote WSL extension
  3. 3. Install Homebrew & Node in WSL

    Search and open Ubuntu from the Start menu. Install Homebrew by executing:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    When prompted, enter your Ubuntu password. The installer will tell you how to add brew to the PATH. Copy those commands and run them one by one in Ubuntu.

    Next, install Homebrew dependencies if you have sudo access:

    sudo apt-get install build-essential

    Verify brew is installed:

    brew -version

    Install Node using Homebrew:

    brew install node@16

    Confirm it works with:

    node -version

    Note: If you have another version of node installed, link this version to Homebrew: brew link node@16

  4. 4. Install DFX

    Open Ubuntu and run this command to install the Dfinity SDK:

    DFX_VERSION=0.9.3 sh -ci "$(curl -fsSL https://sdk.dfinity.org/install.sh)"

    After DFX installs, it will print the installation path (e.g., /home/username/bin/dfx). Add it to your PATH (replace the path below with yours):

    export PATH=$PATH:/home/YOUR_USERNAME/bin/dfx

    Verify that DFX is successfully added:

    dfx --version

macOS Installation

Native macOS Setup


  1. 1. Install Node.js

    Go to the official Node.js website and download the Long Term Support (LTS) version (left button, typically 16.x.x LTS):

    Visit Node.js Downloads
  2. 2. Install DFX

    Open the Terminal app (in Applications folder or search via Spotlight). Copy and paste this command, then press Enter:

    DFX_VERSION=0.9.3 sh -ci "$(curl -fsSL https://sdk.dfinity.org/install.sh)"
  3. 3. Install VSCode & Extensions

    Download and install VSCode for macOS:

    Download VSCode

    Open VSCode and install the Motoko language extension by the Dfinity team:

    Motoko Extension Link

How to run your Web3 projects (DFX):

1
Start Local Replica

Start the local Internet Computer blockchain network:

dfx start
2
Deploy Canisters

Compile and deploy the smart contract backend and assets:

dfx deploy
3
Run Frontend Dev Server

Run the frontend hot-reloading development server:

npm run start
